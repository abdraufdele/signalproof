# SignalProof plugin 0.6.0

See the [project README](../README.md) for configuration, installation, examples, security and limits.

Use Node 24.21.0 and pnpm 11.11.0. From this directory: pnpm install --frozen-lockfile, then pnpm test. Build output is dist/plugin.mjs and stays outside Git. The manifest sample checks an unsigned optional research proposal; it does not pay. Run the read-only regressions listed in the root README separately.
